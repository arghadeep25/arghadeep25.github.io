Graph SLAM

A robot walks, gets a little lost with every step, then fixes its whole map in one go. Watch how.

Walking with your eyes closed

The robot counts its steps. Every count is a tiny bit wrong, and the mistakes add up.

Nodes: a pin for every step

Each time the robot moves, it drops a pin. A pin is a guess: where am I, and which way am I facing?

Edges: a string between two pins

The odometer says what happened between two steps. Tie a string between the pins to hold that fact. If the pins drift away from what the sensor said, the string stretches and pulls them back.

Loop closure: "I have been here!"

Look at the strings before the robot returns: all relaxed, and yet the map is wrong. Then the robot recognises the start. One new string joins the last pin to the first, and that string is very stretched. Every pin on the way gets pulled a little, and the lap snaps shut.

One price for the whole map

Every string charges a price for being stretched. Add the prices up and you get one number for the whole map. The best map is the one with the lowest total.

Rolling down to the best map

The price is a bowl, and the best map is at the bottom. The computer cannot see the whole bowl, only the bit under its feet. So it looks at the slope here, draws a simple curve that hugs the bowl, jumps to the bottom of that curve, and looks again.

Watch the lap settle

The same jumps, on the whole lap. The price drops fast at first, then slows down. After a handful of steps the pins stop moving.

Why we pin the first dot

Every string only knows the gap between two pins. It has no idea where the pins are on the page. So the whole map can slide or spin and the price stays the same. To stop that, we nail the first pin down.

How sure is each pin?

A good map says more than where things are. It also says how sure it is. Each pin wears a cloud: the place it might really be. The cloud grows with every step of counting, and shrinks when a loop closure ties the ends together.

=
Σ: the size of the cloud

How far from its guess a pin might really be. One cloud per pin.

Bigger: a bigger cloud, so the pin is less sure.

Smaller: a tight cloud, so the pin is sure.

H: all the strings together

The same table as before. It measures how firmly the strings hold each pin.

Bigger: more or stiffer strings hold the pin.

Smaller: few or loose strings hold the pin.

−1: flip it over

Held firmly means a small cloud. Held loosely means a big cloud.

Bigger H: the flip makes the cloud smaller.

Smaller H: the flip makes the cloud bigger.
